WEB DEVELOPMENT

HND'25 SWD CBT Portal

A fully functional computer-based test platform developed for the Department of Software and Web Development to provide students with a structured online examination experience.

ROLE Developer
PROJECT TYPE CBT / Educational Platform
TECHNOLOGY HTML • CSS • JavaScript • React
STATUS Deployed

Project Overview

The HND'25 SWD CBT Portal is a functional computer-based testing platform developed for the Department of Software and Web Development.

The platform provides students with a digital examination experience where they can identify themselves, select their course, begin an examination, answer questions, navigate through the test, and receive an automatically generated result.

Project Purpose

The project was developed to provide a practical online solution for conducting computer-based assessments within the school environment.

The goal was to create an examination system that could guide students through the complete testing process while presenting important information clearly and efficiently.

Key Features

✓ Student Identification ✓ Course Selection ✓ Examination Timer ✓ 50-Question Assessment ✓ Multiple-Choice Questions ✓ Question Navigation ✓ Previous / Next Controls ✓ Automatic Scoring ✓ Percentage & Grade Calculation ✓ Pass / Fail Result ✓ Print / Save Result as PDF ✓ Responsive Interface

Examination Experience

The examination interface was designed to keep the student focused on the current question while still providing easy access to the other questions.

Students can view their remaining time, select answers, move between questions, and navigate through the assessment using the Previous and Next controls.

Automated Results

After completing the examination, the system generates a result summary showing the student's information, course, number of questions, correct answers, wrong answers, percentage, grade, and pass or fail status.

The result can also be printed or saved as a PDF, making it easier for students to keep a record of their examination outcome.

User Experience

I focused on making the examination flow straightforward from the moment a student enters the portal until the final result.

Clear labels, structured information, visible navigation controls, readable questions, and a prominent timer help students understand their current position throughout the examination.

The Challenge

One of the main challenges was creating a reliable examination flow that could handle multiple questions, answer selection, navigation, timing, and result calculation while remaining simple for students to use.

My Solution

I structured the application into clear stages: student identification, course selection, examination, question navigation, submission, and result generation.

The interface was designed with responsive layouts and clear visual hierarchy so that students can interact with the system comfortably across different screen sizes.

Technologies Used

HTML CSS JavaScript React

Result

The result is a functional CBT platform that provides students with a complete online examination workflow, from registration details and test access through to automated results.

The project gave me practical experience in building an educational web application around a real-world academic requirement.
